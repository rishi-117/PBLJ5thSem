# Question 1

`Student` is a JPA entity mapped to the `students` table. The id is generated by the
database (`IDENTITY`), and the other four columns are name, email, course and age.

Validation:

- `name`, `email` and `course` are `@NotBlank`, so they can't come in empty.
- `email` is `@Email` and the column is unique, which is what the 409 conflict later relies on.
- `age` is `@Min(1)` - no zero or negative ages.
